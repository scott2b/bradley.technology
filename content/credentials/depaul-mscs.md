Graduate work across software systems and algorithms — object-oriented modeling and
development, computer systems, programming language concepts, design and analysis of
algorithms, network programming — and, running alongside it, a scientific computing
track: proteomics, neural networks and machine learning, cognitive science, an
introduction to computational scientific discovery, and a research practicum in
computational biology.

The scientific computing track began with the proteomics course. The project there
was a persistence layer for Gene Designer, a component of the Illinois Bio-Grid
Protein Desktop that produces DNA sequences coding for a given amino acid sequence.
Researchers could save a run's input parameters, export them, and exchange them with
each other, so that a run could be reproduced. {{ person(id="angulo") }}, who ran the Bio-Grid work at DePaul, was among its stakeholders, and supervised the master's
research that followed.

## Research

Two courses of graduate research with {{ person(id="westneat") }}, then Associate Curator of Zoology
at the Field Museum of Natural History: a practicum in computational biology in 2006,
then the computer science research option through 2008, advised by
{{ person(id="angulo", text="David Angulo") }} and {{ person(id="phillips") }}. Both were the Java desktop version of
Westneat's phylogenetic analysis application **[JackTaxa](/projects/jacktaxa/)**, and
the writeup that went with it.
